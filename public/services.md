# Andishi Services Spec

This catalog defines Andishi's primary software studio service lines, typical timelines, scoping parameters, and deliverables.

## Service Catalog

### 1. Web Applications
- **Slug**: `custom-software`
- **Timeline**: 4–10 weeks
- **Typical Stack**: Next.js, React, Node.js, Python, PostgreSQL, Prisma
- **Scope**: Custom web apps replacing spreadsheets, customer portals, interactive dashboards, and business operations panels.

### 2. SaaS Platforms
- **Slug**: `saas-development`
- **Timeline**: 6–14 weeks
- **Typical Stack**: Next.js, Tailwind CSS, PostgreSQL, Stripe, Clerk, Resend
- **Scope**: Multi-tenant architectures, subscription billing pipelines, role-based user management (RBAC), and analytics dashboards.

### 3. Mobile Applications
- **Slug**: `mobile-apps`
- **Timeline**: 6–12 weeks
- **Typical Stack**: React Native, Expo, Flutter, Swift, Kotlin
- **Scope**: Cross-platform or native iOS and Android apps, offline support, push notifications, and device hardware integrations.

### 4. AI & Intelligent Systems
- **Slug**: `ai-systems`
- **Timeline**: 3–8 weeks
- **Typical Stack**: OpenAI API, LangChain, LlamaIndex, Vector Databases (Pinecone, pgvector), Python
- **Scope**: Large Language Model (LLM) integrations, Retrieval-Augmented Generation (RAG) pipelines, chat agents, and automated data processing.

### 5. Enterprise Software
- **Slug**: `enterprise-software`
- **Timeline**: 8–20 weeks
- **Typical Stack**: Java, Spring Boot, NestJS, AWS, Docker, Kubernetes
- **Scope**: Internal systems, enterprise database migrations, legacy system revamps, custom ERP modules, and high-availability operations panels.

### 6. Blockchain & Web3
- **Slug**: `blockchain`
- **Timeline**: 4–12 weeks
- **Typical Stack**: Solidity, Hardhat, Ethers.js, wagmi, Viem
- **Scope**: Smart contract development and auditing, token-gated features, decentralized database integrations, and on-chain payment rails.

### 7. APIs & Integrations
- **Slug**: `apis-integrations`
- **Timeline**: 2–6 weeks
- **Typical Stack**: Node.js, Express, Fastify, NestJS, Postgres, Redis
- **Scope**: Custom API design and development, third-party service webhooks, data sync pipelines, and payment gate integrations (M-Pesa, Stripe).

### 8. Product Strategy & Design
- **Slug**: `product-strategy`
- **Timeline**: 1–3 weeks
- **Typical Stack**: Figma, Miro, Linear, Product Brief Specs
- **Scope**: UX/UI design wireframes, user journeys, software architecture diagrams, scope-of-work briefs, and technical feasibility studies.

## Engagement Rules

1. **Direct Communication**: Clients collaborate directly with the lead software developers. No account managers or translator layers.
2. **Weekly sprint demos**: Active work is demonstrated in live environments every Friday.
3. **No Code Silos**: Code is pushed to client-owned or shared GitHub repositories in real-time.
4. **Complete IP Handover**: Complete ownership of codebases, databases, domains, and design files is transferred upon project completion.
5. **Post-Launch Support**: Every build includes a 30-day post-launch warranty window for bug fixes and deployment support.
